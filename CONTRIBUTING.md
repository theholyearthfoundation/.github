# Contributing

This file applies as the default contributing guide for any repository under the
`theholyearthfoundation` organization that doesn't have its own `CONTRIBUTING.md`.

## Before you contribute

This organization's projects touch sacred and personal material — spiritual teaching, retreat
content, and the visionary art and teaching lineage of Maestro David Amaringo and Chaiconi Bari.
Approach contributions to content (not just code) with care for that context; when in doubt about
whether something is appropriate to change, open an issue and ask first rather than submitting a
pull request.

## How to contribute

1. For a small fix (typo, broken link), a pull request alone is fine.
2. For anything larger — new content, structural changes — open an issue first to discuss it.
3. Fork the repository, keep your branch focused on one change, and explain *why* in the commit
   message, not just what changed.

## Reporting problems

For security issues, see [`SECURITY.md`](./SECURITY.md) instead of a public issue. For anything
else, a regular GitHub issue is the right place.

## Questions

This organization is early-stage and this guide will get more specific as its projects grow. If
something here doesn't fit, ask.
