# Security Policy

This file applies as the default security policy for any repository under the
`theholyearthfoundation` organization that doesn't have its own `SECURITY.md`.

## Reporting a Vulnerability

If you find a security issue in a project maintained under this organization, please report it
privately rather than opening a public issue, so it can be addressed before wider disclosure.

**Contact:** open a private security advisory on the relevant repository (GitHub's "Report a
vulnerability" flow under the Security tab), or reach out to Christopher Wilson, who maintains this
organization's technical infrastructure, via the contact details on his
[GitHub profile](https://github.com/drasticstatic).

Please include:
- A description of the issue and where you found it
- Steps to reproduce, if applicable
- Any potential impact you're aware of

## Scope

This applies to code and infrastructure under this organization's direct control. This is a small,
early-stage organization — response times may vary, but every report will be read.
